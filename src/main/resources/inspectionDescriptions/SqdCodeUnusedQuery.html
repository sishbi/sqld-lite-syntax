Reports a query label in a .sq or .sqm file that no Kotlin code calls.

SqlDelight generates a function for every labelled query. A label with no call site generates a function nobody uses, and Go To Declaration on it reaches nothing. This inspection greys the label out, so an unused query reads as unused rather than as a failed jump.

The search looks for a call on a generated ...Queries class whose name matches the label. A query called only through reflection is therefore reported as unused.
